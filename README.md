
# 🎮 VoiceCut AI

AI-powered Free Fire Voiceover Video Editor.

## Features

- Upload gameplay video
- Upload voiceover audio
- Rearrange Mode
- Original Gameplay Mode
- Both Modes
- 720p, 1080p and 4K export options

## Technology

- Python
- Streamlit
- Whisper
- FFmpeg
- OpenCV

## Run locally

Install dependencies:

pip install -r requirements.txt

Start application:

streamlit run app.py
